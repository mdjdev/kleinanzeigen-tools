## [1.0.0] - 2026-08-05

### Added
- Initial release of the userscript.
- "Anzeige duplizieren" button to create a new listing from the current edit form.
- "Neu einstellen" button to delete the original listing and create a replacement.
- Floating control panel rendered independently of Kleinanzeigen UI classes.
- Status messages showing the detected ad ID and operation results.
